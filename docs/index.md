# ChainTransfer

**ChainTransfer** é um sistema distribuído de replicação de arquivos entre dispositivos em rede local. Cada nó detecta automaticamente seus pares e sincroniza arquivos ausentes, criando uma malha autônoma de troca de dados.

## Objetivos

- Transferência automática de arquivos entre nós
- Uso de rede local sem necessidade de servidor central
- Baixo consumo e autonomia
