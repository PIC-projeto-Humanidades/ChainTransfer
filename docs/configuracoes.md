# Configurações e Scripts

- **.eslintrc.js**: Regras de lint para JavaScript/TypeScript.
- **.prettierrc**: Configurações de formatação de código.
<!-- - **Dockerfile**: Imagem Docker do backend. -->
<!-- - **docker-compose.yml**: Orquestra serviços (app, DB). -->
- **nest-cli.json**: Configuração do CLI NestJS.
- **tsconfig.json** / **tsconfig.build.json**: Configurações TypeScript.
- **package.json** / **package-lock.json**: Dependências e scripts npm.

## Scripts Principais

- `npm run start`: Inicia em modo desenvolvimento.
- `npm run build`: Compila para `dist/`.
- `npm run lint`: Executa ESLint.
